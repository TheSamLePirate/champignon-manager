Mode d’emploi rapide

Le navigateur sauvegarde automatiquement les réponses sur cet appareil. Mais pour transmettre ou sécuriser le travail, il faut cliquer sur Exporter JSON. Le fichier JSON contient les réponses, les questions modifiées, les statuts, les cases cochées et les tableaux.

Les encadrés verts ✅ « Validé par le cultivateur » rappellent les principes déjà actés le 30/07/2026 : leur réponse est déjà écrite dans le champ de réponse. Tu peux la compléter ou la modifier librement — le bouton « Restaurer la réponse validée » remet le texte d’origine si besoin.

Les encadrés orange ⏳ « Reste à préciser » sont le vrai travail restant : les durées, températures, ratios, seuils d’alarme et mots exacts que seul le terrain connaît. Les questions concernées sont marquées « À clarifier », et le filtre « Ce qui reste à préciser » permet de n’afficher qu’elles.

Note sur la progression. Une question sans texte ni case cochée est comptée « À répondre », même si elle avait été marquée comme répondue lors d’une passe précédente. C’est volontaire : le pourcentage doit refléter ce qui est réellement écrit, sinon il donne une fausse impression d’avancement.

Pour n’avoir que le travail restant, clique sur 🎯 Questions à répondre en haut de page — ou sur n’importe quelle tuile de compteur dans la colonne de gauche (répondues, à clarifier, à répondre…). Un second clic sur la même tuile réaffiche tout. La recherche se combine avec le filtre.
Une question ne disparaît pas pendant que tu écris dedans, même si elle passe en « Répondu » dès la première lettre : la liste reste figée tant que tu travailles. Le bouton ↻ Rafraîchir la liste apparaît alors dans le bandeau bleu pour recalculer ce qu’il reste.
